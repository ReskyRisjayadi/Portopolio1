## 🚀 Cara Menjalankan Website Secara Lokal

Website ini **100% Client-Side** tanpa memerlukan instalasi Node.js, PHP, atau database apa pun:

1. **Buka folder proyek:** `d:\project\Portopolio`

## 🛠️ Panduan Mengganti Foto Profil Asli

1. **Cara Paling Cepat (Langsung di Web):**
   - Buka `index.html` di peramban Anda.
   - Pada foto profil di halaman pembuka (Hero Section), klik tombol **"Ganti Foto"**.
   - Pilih file foto Anda (JPG, PNG, atau WebP) dari laptop.
   - Foto akan langsung tampil dan tersimpan di penyimpanan browser (`localStorage`).
2. **Cara File:**
   - Salin file foto Anda ke dalam folder `assets/images/` (contoh: `assets/images/foto-resky.jpg`).
   - Buka `index.html` dan ubah atribut `src` pada elemen `#heroAvatarImg`:
     ```html
     <img src="assets/images/foto-resky.jpg" alt="Foto Profil Resky Risjayadi" id="heroAvatarImg" class="avatar-img">
     ```
